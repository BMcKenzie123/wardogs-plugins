# Risk register: legal, safety, operational

Plain-language view of what running these servers and this tooling exposes the unit to, what is already
in place, and what is still open. Not legal advice; the items marked "confirm" need a decision by TAW
leadership or a check against the relevant terms.

## 1. Player safety and fair process

| Risk                                                                                                                                                           | In place                                                                                                                                                                                                   | Open                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Bans with no recourse.** A ban is a decision about a person; without an appeal path it is arbitrary and, with a TAW tag on the server, reflects on the unit. | Every ban carries "Appeal at discord.gg/taw". Every admin action is recorded with the admin's name, the target, the stated reason and the outcome (`data/admin-actions.jsonl`). Temp bans lift themselves. | A channel and a named person to answer appeals within 24 h (blocker #15). A written ban ladder: warn, kick, temp, permanent. |
| **Harassment, hate, threats** between players, in a space TAW hosts.                                                                                           | Rules draft (COPY.md). Admins can kick, DM, temp-ban and ban from the panel in seconds.                                                                                                                    | A reporting path players are told about (#15). The API cannot read chat, so reports are the only signal (blocker #6).        |
| **Minors.** Players may be under 18; admins DM them directly.                                                                                                  | Every DM is a fixed template, logged, and contains only the game and the Discord invite.                                                                                                                   | Confirm TAW's age policy and whether the Discord invite in every DM is appropriate for the game's audience.                  |
| **Admin abuse of power.** Any panel login can ban anyone permanently.                                                                                          | Named logins; nothing is anonymous; the durable action log.                                                                                                                                                | Roles (moderator vs admin) so not every login can permanently ban or rewrite config (dev plan v2.1, blocker #8).             |

## 2. Personal data (GDPR applies: the EU server, EU players on NA, and the box is in Finland)

What we hold, per player: SteamID64, in-game name, Steam persona name and avatar URL (from Steam, cached),
country code (Steam), session times and totals, kills/deaths per session, visit counts, ban records with
reasons, temp-ban expiries, and admin actions naming the target. We do **not** hold player IP addresses,
chat, positions or anything the API does not return.

| Risk                                                                                                                                                        | In place                                                                                          | Open                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No lawful basis stated, no notice.** A SteamID is personal data.                                                                                          | Data lives on one box in the EU (Hetzner, Finland), loopback-only app, HTTPS panel, key-only SSH. | A one-paragraph privacy notice in the Discord rules channel: what is kept, why (running and moderating the server), for how long, how to ask for it or have it removed. Confirm with TAW leadership whether TAW already has one that covers game servers. |
| **Indefinite retention.** Stats and logs grow forever by default.                                                                                           | Everything is plain files under `data/`, easy to prune.                                           | Decide retention: proposal 90 days for stats snapshots and sessions, 1 year for admin actions, bans until lifted, profiles refreshed daily and dropped when unseen for 90 days. Then a nightly prune job.                                                 |
| **Access and erasure requests.** A player asks what you hold or asks to be forgotten.                                                                       | All data is keyed by SteamID64 and greppable.                                                     | A `wd forget <steamId>` command that removes the player from stats, state and profiles while keeping an active ban (a ban is a legitimate interest). Named owner: server lead.                                                                            |
| **Third parties see data.** Steam (lookups), Discord (once the webhook exists: names and SteamIDs in posts), imgbb (banner only), xREALM (the game itself). | Steam lookups are batched and cached; nothing is sent to Discord yet.                             | Keep SteamIDs out of public Discord posts where a name will do; keep ban posts in an admin-only channel.                                                                                                                                                  |

## 3. Credentials and platform

| Risk                                                                                                                                                                                         | In place                                                                                                                                                        | Open                                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **The RCON password is full control** of the game server: bans, config, match control. xREALM exposes RCON over **plain HTTP**, so the token crosses the internet unencrypted on every call. | Password entered only via a silent prompt on the box, never in chat or git; `.env` mode 600; one keep-alive connection, so it is sent as few times as possible. | Nothing on our side can encrypt xREALM's listener. Ask xREALM for TLS on the mapped port, or accept the exposure and rotate the password if anything looks off. |
| **Panel exposed on the public internet.** Basic auth over HTTPS, three named logins, no lockout yet.                                                                                         | HTTPS via Let's Encrypt; passwords stored as scrypt hashes; CSRF and origin checks; every action logged under the login.                                        | Login lockout and session cookies (v2.1). Until then, long unique passwords only and share them one to one.                                                     |
| **A compromised admin password = a compromised server.** Same power as the RCON token.                                                                                                       | Rotation is one command (`wd admin-hash <name>`).                                                                                                               | Roles (v2.1) so a moderator's password is worth less than an owner's.                                                                                           |
| **Single box, no backups.** Disk loss = all stats, bans records, sessions and config backups gone.                                                                                           | The game's own ban list lives on the game server; `config-backup` keeps config snapshots under `data/`.                                                         | Nightly backup of `data/`, `plugins.json` and `.env` to a second location, and one tested restore (v2.1).                                                       |

## 4. Content and terms

| Risk                                                                                                                    | In place                                                                                                                        | Open                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Sponsor banner rules.** An inappropriate image on the server row gets the server blacklisted by the game's publisher. | Only approved hosts accepted (catbox, imgbb, postimg); the panel and CLI refuse anything else; the banner is TAW's own artwork. | Nobody but the server lead should change the banner (roles, v2.1).                                                                         |
| **Steam Web API terms.** The key is personal to whoever created it and governs how the data may be used and cached.     | Lookups only for players, bans and reserved slots; cache one hour in memory, profiles refreshed daily.                          | Confirm the key holder is comfortable with the key living on the box, and read the terms for caching limits before adding more Steam data. |
| **What the server says to players** reflects on TAW. Broadcasts and DMs are TAW's words.                                | Every line is in COPY.md, editable only by panel logins, every change logged.                                                   | Sign-off on the copy and the rules by the server lead (blocker #1).                                                                        |
| **Discord's terms** once the hookup exists (webhook use, rate limits, content).                                         | The relay posts at most one message per second and drops beyond a backlog.                                                      | Keep webhook posts to server events; no player-to-player content is relayed (the API cannot read chat anyway).                             |

## 5. What is deliberately not done

- No player IP logging. The API does not provide it and nothing here asks for it.
- No chat capture. Not possible via the API, and not wanted.
- No automated permanent bans. Every automated action in the kit is a warning, a kick or a temp ban; a permanent ban is always a human decision, logged under a name.
